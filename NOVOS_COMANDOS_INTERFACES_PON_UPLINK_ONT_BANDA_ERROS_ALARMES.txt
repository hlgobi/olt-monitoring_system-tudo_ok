| Linha do Resultado                                     | Nome Amigável              | Explicação Detalhada                                                                                                                       |
| ------------------------------------------------------ | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **F/S/P (contextual, do comando anterior)**            | Identificador da Porta PON | Mostra qual porta GPON (Frame/Slot/Porta) os dados de tráfego pertencem. É essencial para relacionar métricas com a interface correta.     |
| **Up traffic (kbps)**                                  | Tráfego Subida (kbps)      | Volume de dados transmitidos **dos clientes para a OLT**. Importante para medir consumo de upload agregado na porta.                       |
| **Down traffic (kbps)**                                | Tráfego Descida (kbps)     | Volume de dados transmitidos **da OLT para os clientes**. Representa o tráfego de download agregado.                                       |
| **Traffic of upstream broadcast frames (packets/s)**   | Broadcast Subida (p/s)     | Número de pacotes broadcast enviados **pelos clientes para a OLT** por segundo. Normalmente baixo, mas pode indicar anomalias se aumentar. |
| **Traffic of upstream multicast frames (packets/s)**   | Multicast Subida (p/s)     | Pacotes multicast enviados **dos clientes para a OLT** por segundo. Relevante em cenários de IPTV ou replicação de tráfego.                |
| **Traffic of upstream unicast frames (packets/s)**     | Unicast Subida (p/s)       | Pacotes unicast (com destino único) enviados **pelos clientes para a OLT**. A maior parte do tráfego real costuma estar aqui.              |
| **Traffic of downstream broadcast frames (packets/s)** | Broadcast Descida (p/s)    | Pacotes broadcast enviados **da OLT para todos os clientes** por segundo. Deve ser monitorado, pois broadcast excessivo degrada a rede.    |
| **Traffic of downstream multicast frames (packets/s)** | Multicast Descida (p/s)    | Pacotes multicast enviados **da OLT para os clientes**. Muito usado em IPTV para replicação eficiente de fluxos.                           |
| **Traffic of downstream unicast frames (packets/s)**   | Unicast Descida (p/s)      | Pacotes unicast enviados **da OLT para clientes específicos**. É o tráfego de download “normal” da rede.                                   |
}
